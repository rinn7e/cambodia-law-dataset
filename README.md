# Cambodia Law Dataset

A comprehensive, structured collection of Cambodian laws and legal documents. This project transforms official legal texts into machine-readable Markdown, featuring high-quality AI-assisted English translations.

## Features

- **Markdown Format**: All laws are converted to clean, structured Markdown for easy reading and integration.
- **AI-Powered English Translations**: Many documents include high-quality English translations generated by AI, with technical terms accompanied by their original Khmer in brackets.
- **Original Source**: When possible (and when file sizes allow), the original PDF sources are included for reference.
- **Organized Structure**: Laws are categorized with consistent naming conventions and versioning.

## Dataset Structure

The dataset is organized within the `dataset/` directory. Each law is contained in its own subdirectory:

```bash
dataset/
└── [law-identifier]/
    ├── [law-identifier].md (Original Khmer Version)
    ├── [law-identifier]-en.md (AI-Generated English Translation)
    └── [law-identifier].pdf (Original PDF Document, optional)
```

## Current Laws

The dataset is categorized by a priority score (0 being the most critical, such as the Constitution). Click on the links to view the structured Markdown files.

## Translation Methodology

The English versions are generated using advanced LLMs (Gemini) following a set of strict translation rules:
- Preservation of original document structure and formatting.
- Inclusion of original Khmer terms in brackets for legal or technical terms: e.g., `Jurisdiction (សមត្ថកិច្ច)`.
- Use of formal, standard English suitable for official documents.
- Mental correction of OCR-related typos in the original Khmer before translation.
