## ចុះថ្ងៃទី១៧ ខែមិថុនា ឆ្នាំ២០១១

## ( មានចំនួន ៨ជំពូក និង ៩៦មាត្រា )

ព្រះរាជក្រមលេខ នស/រកម/០៦១១/០១១ ប្រកាសឲ្យប្រើ ច្បាប់ស្តីពីរបបហិរញ្ញវត្ថុ និងការគ្រប់គ្រងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

**ជំពូកទី១ បទប្បញ្ញត្តិទូទៅ**

( មាត្រា១ដល់មាត្រា៥ )

**ជំពូកទី២ សមត្ថកិច្ច និងការគ្រប់គ្រងហិរញ្ញវត្ថុ និងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ**

( មាត្រា៦ដល់មាត្រា១៦ )

**ជំពូកទី៣ ថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ**

( មាត្រា១៧ដល់មាត្រា៤៦ )

**ផ្នែកទី១ គោលការណ៍គ្រប់គ្រងថវិកា**

( មាត្រា១៧ដល់មាត្រា២២ )

**ផ្នែកទី២ បន្ទុក និងធនធានហិរញ្ញវត្ថុរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ**

( មាត្រា២៣ដល់មាត្រា៣៣ )

**ផ្នែកទី៣ ការរៀបចំនិងការអនុម័តថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ**

( មាត្រា៣៤ដល់មាត្រា៣៦ )

**ផ្នែកទី៤ ការអនុវត្តថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ**

( មាត្រា៣៧ដល់មាត្រា៤៦ )

**ជំពូកទី៤ ការគ្រប់គ្រងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ**

( មាត្រា៤៧ដល់មាត្រា៥១ )

**ជំពូកទី៥ បទប្បញ្ញត្តិដោយឡែក**

( មាត្រា៥២ )

**ជំពូកទី៦ ទោសប្បញ្ញត្តិ**

( មាត្រា៥៣.- )

**ជំពូកទី៧ អន្តរប្បញ្ញត្តិ**

( មាត្រា៥៤ )

**ជំពូកទី៨ អវសានប្បញ្ញត្តិ**

( មាត្រា៥៥ដល់មាត្រា៩៦ )

# ព្រះរាជក្រម

## នស/រកម/០៦១១/០១១

### យើង

**ព្រះករុណាព្រះបាទសម្តេចព្រះបរមនាថ នរោត្តម សីហមុនី**

**សហសភូមិជាតិសាសនា រក្ខតខត្តិយា ខេមរារដ្ឋរាស្ត្រ ពុទ្ធិន្ទ្រាធរាមហាក្សត្រ**

**ខេមរាខត្តិយា មហាសាមុហោភាស កម្ពុជឯករាជរដ្ឋបូរណសន្តិ សុភមង្គលា សិរីវិបុលា**

**ខេមរាស្រីពិរាស្ត្រ ព្រះចៅក្រុងកម្ពុជាធិបតី**

- បានទ្រង់យល់ រដ្ឋធម្មនុញ្ញនៃព្រះរាជាណាចក្រកម្ពុជា

- បានទ្រង់យល់ ព្រះរាជក្រឹត្យលេខ នស/រកត/០៩០៨/១០៥៥ ចុះថ្ងៃទី២៥ ខែកញ្ញា ឆ្នាំ២០០៨ ស្តីពីការតែងតាំងរាជរដ្ឋាភិបាលនៃព្រះរាជាណាចក្រកម្ពុជា

- បានទ្រង់យល់ ព្រះរាជក្រមលេខ ០២/នស/៩៤ ចុះថ្ងៃទី២០ ខែកក្កដា ឆ្នាំ១៩៩៤ ដែលប្រកាសឲ្យប្រើច្បាប់ស្តីពីការរៀបចំនិងការប្រព្រឹត្តទៅនៃគណៈរដ្ឋមន្ត្រី

- បានទ្រង់យល់ ព្រះរាជក្រមលេខ នស/រកម/០១៩៦/១៨ ចុះថ្ងៃទី២៤ ខែមករា ឆ្នាំ១៩៩៦ ដែលប្រកាសឲ្យប្រើច្បាប់ស្តីពីការបង្កើតក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ

- បានទ្រង់យល់ សេចក្តីក្រាបបង្គំទូលថ្វាយ របស់សម្តេចអគ្គមហាសេនាបតីតេជោ ហ៊ុន សែន នាយករដ្ឋមន្ត្រី នៃព្រះរាជាណាចក្រកម្ពុជា និងរដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ

## ប្រកាសឲ្យប្រើ

ច្បាប់ ស្តីពីរបបហិរញ្ញវត្ថុ និងការគ្រប់គ្រងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ដែលរដ្ឋសភាបានអនុម័ត កាលពីថ្ងៃទី១១ ខែឧសភា ឆ្នាំ២០១១ នាសម័យប្រជុំរដ្ឋសភាលើកទី៦ នីតិកាលទី៤ និងដែលព្រឹទ្ធសភាបានយល់ស្របតាមទម្រង់និងគតិនៃច្បាប់នេះទាំងស្រុងដោយគ្មានការកែប្រែអ្វីឡើយ កាលពីថ្ងៃទី៣១ ខែឧសភា ឆ្នាំ២០១១ នាសម័យប្រជុំពេញអង្គលើកទី៩ នីតិកាលទី២ ហើយដែលមានសេចក្តីទាំងស្រុងដូចតទៅនេះ :

## ស្តីពី

# របបហិរញ្ញវត្ថុនិងការគ្រប់គ្រងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

# ជំពូកទី ១

## បទប្បញ្ញត្តិទូទៅ

### មាត្រា ១.-

ច្បាប់នេះ មានគោលដៅកំណត់អំពីរបបហិរញ្ញវត្ថុ និង ការគ្រប់គ្រងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ នៅក្នុងព្រះរាជាណាចក្រកម្ពុជា ។

### មាត្រា ២.-

ច្បាប់នេះ មានគោលបំណងបង្កើតនូវប្រភពធនធានហិរញ្ញវត្ថុ ដើម្បីឲ្យរដ្ឋបាលថ្នាក់ក្រោមជាតិ មានលទ្ធភាពសមស្រប ក្នុងការអភិវឌ្ឍមូលដ្ឋានតាមបែបប្រជាធិបតេយ្យប្រកបដោយចីរភាព និងលើកកម្ពស់ការអនុវត្តគោលនយោបាយវិមជ្ឈការ និងវិសហមជ្ឈការរបស់រាជរដ្ឋាភិបាល ដើម្បីកាត់បន្ថយភាពក្រីក្ររបស់ប្រជាពលរដ្ឋ ។

### មាត្រា ៣.-

ច្បាប់នេះ មានវិសាលភាពអនុវត្តចំពោះរបបហិរញ្ញវត្ថុ និង ការគ្រប់គ្រងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលរាជធានី ខេត្ត ក្រុង ស្រុក ខណ្ឌ ក្នុងព្រះរាជាណាចក្រកម្ពុជា ។

ច្បាប់នេះ មិនមានវិសាលភាពអនុវត្តចំពោះរបបហិរញ្ញវត្ថុ និង ការគ្រប់គ្រងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលឃុំ សង្កាត់ទេ លើកលែងតែមានបទប្បញ្ញត្តិដែលចែងក្នុងច្បាប់នេះ ។

### មាត្រា ៤.-

រដ្ឋបាលរាជធានី ខេត្ត ក្រុង ស្រុក ខណ្ឌ ឃុំ សង្កាត់ ហៅកាត់ថា "រដ្ឋបាលថ្នាក់ក្រោមជាតិ" គឺជានីតិបុគ្គលនៃនីតិសាធារណៈដែលមានទ្រព្យសម្បត្តិ ធនធានហិរញ្ញវត្ថុ និង ថវិការផ្ទាល់របស់ខ្លួន ។

នៅក្នុងក្របខ័ណ្ឌនៃច្បាប់នេះ ពាក្យថា "រដ្ឋបាលថ្នាក់ក្រោមជាតិ" គឺសំដៅដល់រដ្ឋបាលរាជធានី ខេត្ត ក្រុង ស្រុក ខណ្ឌ ។

### មាត្រា ៥.-

ក្នុងការគ្រប់គ្រងកិច្ចការហិរញ្ញវត្ថុ និង ថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវអនុវត្តតាមគោលការណ៍ជាមូលដ្ឋាន ដូចមានចែងនៅក្នុង មាត្រា ២ មាត្រា ៥ និង មាត្រា ៦ នៃច្បាប់ស្តីពីប្រព័ន្ធហិរញ្ញវត្ថុសាធារណៈ ។

## សមត្ថកិច្ច និង ការគ្រប់គ្រងហិរញ្ញវត្ថុ និង ទ្រព្យសម្បត្តិ របស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

### មាត្រា ៦.-

ក្រុមប្រឹក្សានីមួយៗត្រូវធ្វើជាតំណាង និង ធ្វើសកម្មភាពក្នុងនាមប្រជាពលរដ្ឋ និងត្រូវចាត់ចែងកិច្ចការហិរញ្ញវត្ថុសាធារណៈ ដើម្បីជម្រុញដល់ការអភិវឌ្ឍតាមបែបប្រជាធិបតេយ្យប្រកបដោយចីរភាពនៅក្នុងដែនសមត្ថកិច្ចរបស់ខ្លួន ។ ក្រុមប្រឹក្សាត្រូវគ្រប់គ្រង និង ចាត់ចែងកិច្ចការហិរញ្ញវត្ថុឲ្យមានប្រសិទ្ធភាព តម្លាភាព និង គណនេយ្យភាពចំពោះប្រជាពលរដ្ឋរបស់ខ្លួន និង ចំពោះរាជរដ្ឋាភិបាលដែលមានក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុជាសេនាធិការ ។

### មាត្រា ៧.-

ក្នុងការគ្រប់គ្រងហិរញ្ញវត្ថុ និង ទ្រព្យសម្បត្តិ ក្រុមប្រឹក្សានៃរដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗត្រូវទទួលខុសត្រូវ ដូចខាងក្រោម :

- ពិនិត្យ និង អនុម័តផែនការអភិវឌ្ឍ កម្មវិធីវិនិយោគបីឆ្នាំរំកិល និង ក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យម

- ពិនិត្យ និង អនុម័តផែនការយុទ្ធសាស្ត្រថវិកា និង គម្រោងថវិកាប្រចាំឆ្នាំដែលដាក់ជូនដោយអភិបាល និង មានសិទ្ធិក្នុងការផ្លាស់ប្តូរថវិកា ក្នុងករណីការផ្លាស់ប្តូរមិនរំលោភច្បាប់ បទបញ្ជា ឬ គោលការណ៍នៃការរៀបចំថវិកា

- ពិនិត្យ និង អនុម័តការកែសម្រួលថវិកាទៅតាមសំណើរបស់អភិបាល

- ពិនិត្យ និង អនុម័តរបាយការណ៍ហិរញ្ញវត្ថុប្រចាំឆ្នាំ

- ពិនិត្យ និង អនុម័តការជម្រះបញ្ជីទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិស្របតាមវិធាន និង បទបញ្ជាជាធរមាន

- តាមដានត្រួតពិនិត្យការអនុវត្តហិរញ្ញវត្ថុ និង ថវិការបស់អភិបាល

- ពិនិត្យ និង អនុម័តកិច្ចសន្យាកិច្ចព្រមព្រៀងដែលបង្កើតការសន្យាហិរញ្ញវត្ថុ ឬ អត្ថប្រយោជន៍លើសពីឆ្នាំថវិកាកំពុងអនុវត្ត ។

### មាត្រា ៨.-

អភិបាលនៃគណៈអភិបាលរាជធានី ខេត្ត ក្រុង ស្រុក ខណ្ឌ មានតួនាទីជាតំណាងក្រសួង ស្ថាប័ននានារបស់រាជរដ្ឋាភិបាលនៅក្នុងដែនសមត្ថកិច្ចរបស់ក្រុមប្រឹក្សានីមួយៗ នៅក្នុងវិស័យ

ហិរញ្ញវត្ថុ អភិបាលនៃគណៈអភិបាលក្នុងនាមក្រុមប្រឹក្សារបស់ខ្លួន ជាអ្នកប្រតិបត្តិផ្ទាល់តាមដីកា និង សេចក្តីសម្រេចរបស់ក្រុមប្រឹក្សាក្នុងការអនុវត្តច្បាប់នេះ ។

### មាត្រា ៩.-

អភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវទទួលខុសត្រូវចំពោះកិច្ចការដូចខាងក្រោម :

- រៀបចំផែនការអភិវឌ្ឍ កម្មវិធីវិនិយោគបីឆ្នាំរំកិល និង ក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យមដែលត្រូវធ្វើបច្ចុប្បន្នភាពជាចរន្តរាល់ឆ្នាំ

- រៀបចំផែនការយុទ្ធសាស្ត្រថវិកា និងគម្រោងថវិកាប្រចាំឆ្នាំ

- អនុវត្តផែនការសកម្មភាព និង គម្រោងថវិកាប្រចាំឆ្នាំ ដែលក្រុមប្រឹក្សាបានអនុម័ត ស្របទៅតាមវិធាននិងនីតិវិធីគ្រប់គ្រងហិរញ្ញវត្ថុជាធរមាន

- រាយការណ៍ជាទៀងទាត់ជូនក្រុមប្រឹក្សាអំពីការអនុវត្តផែនការសកម្មភាព និង គម្រោងថវិកាប្រចាំឆ្នាំ

- រៀបចំរបាយការណ៍ហិរញ្ញវត្ថុប្រចាំឆ្នាំ របាយការណ៍អនុវត្តចំណូលចំណាយថវិកាប្រចាំឆ្នាំ និង របាយការណ៍ផ្សេងៗទៀតដាក់ជូនក្រុមប្រឹក្សាពិនិត្យ និងអនុម័តតាមការកំណត់

- រាយការណ៍ជាទៀងទាត់ជូនក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ និង ក្រសួងស្ថាប័នពាក់ព័ន្ធអំពីការអនុវត្ត និង ស្ថានភាពហិរញ្ញវត្ថុរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ក្រោយពេលដែលរបាយការណ៍នានាបានអនុម័តដោយក្រុមប្រឹក្សារួចហើយ

- គ្រប់គ្រងទ្រព្យសម្បត្តិសាធារណៈនៅក្នុងដែនសមត្ថកិច្ចរបស់ក្រុមប្រឹក្សា និង ថែរក្សាទ្រព្យសម្បត្តិដែលថ្នាក់ជាតិប្រគល់ឲ្យកាន់កាប់នៅក្នុងក្របខ័ណ្ឌច្បាប់ និងបទបញ្ជាជាធរមាន ។

### មាត្រា ១០.-

ប្រធានហិរញ្ញវត្ថុនៃរដ្ឋបាលថ្នាក់ក្រោមជាតិ មានតួនាទីជាអ្នកទទួលខុសត្រូវផ្ទាល់ក្នុងការជួយក្រុមប្រឹក្សា និង អភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិឲ្យសម្រេចបាននូវរាល់ភារកិច្ចដូចបានបញ្ជាក់ក្នុង មាត្រា ៧ និង មាត្រា ៩ នៃច្បាប់នេះ ។

ប្រធានហិរញ្ញវត្ថុត្រូវបំពេញតួនាទីខាងលើនេះ ដោយមានការសម្របសម្រួលពីនាយករដ្ឋបាល និង មានកិច្ចសហការជាមួយអង្គភាពនានានៃរដ្ឋបាលថ្នាក់ក្រោមជាតិ ។

ប្រធានហិរញ្ញវត្ថុនៃរដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវទទួលខុសត្រូវក្នុងការគ្រប់គ្រងហិរញ្ញវត្ថុនៅក្រោមសិទ្ធិអំណាចអភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ។

ប្រធានហិរញ្ញវត្ថុត្រូវបានតែងតាំងដោយក្រុមប្រឹក្សា បន្ទាប់ពីមានការយល់ព្រមពីរដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុតាមសំណើរបស់រដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។

បែបបទនៃការជ្រើសរើស តែងតាំង និង ការកំណត់លក្ខណៈសម្បត្តិប្រធានហិរញ្ញវត្ថុត្រូវកំណត់ដោយប្រកាសអន្តរក្រសួងរបស់រដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ និងរដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ ។

### មាត្រា ១១.-

ចំពោះវិស័យហិរញ្ញវត្ថុនៅក្នុងក្របខ័ណ្ឌនៃបទប្បញ្ញត្តិទាំងឡាយក្នុងជំពូកទី ៣ នៃច្បាប់នេះ អភិបាលនៃគណៈអភិបាលក្នុងនាមក្រុមប្រឹក្សាគឺជាអាណាប័កដើមខ្សែ ជាអ្នករៀបចំ និង អនុវត្តថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ។

ក្នុងការអនុវត្តថវិកាស្របតាមបទប្បញ្ញត្តិនៃច្បាប់ស្តីពីប្រព័ន្ធហិរញ្ញវត្ថុសាធារណៈ អភិបាលនៃគណៈអភិបាលក្នុងនាមក្រុមប្រឹក្សាជាអ្នកបញ្ជាក់ចំណូល សន្យាចំណាយ ជម្រះបញ្ជី និង បញ្ជាចំណាយដោយផ្អែកលើថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិដែលបានអនុម័ត និង ជាអ្នកគ្រប់គ្រង បង្កើត និង បញ្ចប់គណនីរដ្ឋបាល ។

អភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ អាចផ្ទេរសិទ្ធិជាលាយលក្ខណ៍អក្សរក្នុងការសម្រេចលើវិក័យប័ត្រទៅអភិបាលរងណាម្នាក់ ជាអាណាប័កផ្ទេរសិទ្ធិដែលធ្វើសកម្មភាពដោយស្ថិតនៅក្នុងការទទួលខុសត្រូវ និង ត្រួតពិនិត្យរបស់អភិបាល ។ អាណាប័ក និង អាណាប័កផ្ទេរសិទ្ធិត្រូវតម្កល់គំរូហត្ថលេខាជាផ្លូវការដល់គណនេយ្យករសាធារណៈ ។

### មាត្រា ១៣.-

ខណ្ឌ និង សង្កាត់ចំណុះរាជធានី ត្រូវមានថវិការបស់ខ្លួនស្ថិតនៅក្នុងថវិការបស់រាជធានី ។ អភិបាលខណ្ឌ និង ចៅសង្កាត់របស់រាជធានី ជាអាណាប័កផ្ទេរសិទ្ធិពីអភិបាលរាជធានីចំពោះថវិការបស់ខ្លួន ។

សង្កាត់ចំណុះក្រុងត្រូវមានថវិការបស់ខ្លួនស្ថិតនៅក្នុងថវិការបស់ក្រុង ។ ចៅសង្កាត់របស់ក្រុងជាអាណាប័កផ្ទេរសិទ្ធិពីអភិបាលក្រុងចំពោះថវិការបស់ខ្លួន ។

ទម្រង់រចនាសម្ព័ន្ធ និង នីតិវិធីនៃការដាក់បញ្ចូលថវិកាខណ្ឌ និង សង្កាត់ ទៅក្នុងថវិការាជធានី និង ថវិកាសង្កាត់ទៅក្នុងថវិការក្រុង ត្រូវកំណត់ដោយប្រកាសរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ បន្ទាប់ពីបានពិភាក្សាជាមួយរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។

### មាត្រា ១៤.-

ការកាន់កាប់ប្រាក់កាសរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវធានាដោយគណនេយ្យករសាធារណៈរបស់រតនាគារ ដែលទទួលអនុវត្តពីអាណាប័កនៃរដ្ឋបាលថ្នាក់ក្រោមជាតិ ដោយគោរពតាមយ៉ាងម៉ឺងម៉ាត់នូវគោលការណ៍ត្រួតពិនិត្យ និង គ្រប់គ្រងគណនេយ្យសាធារណៈជាធរមាន ។

### មាត្រា ១៥.-

រតនាគារនៅថ្នាក់ក្រោមជាតិ ត្រូវបំពេញមុខងារជាគណនេយ្យករសាធារណៈរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ និងត្រូវអនុវត្តភារកិច្ចទាំងឡាយ ដូចខាងក្រោម :

- ប្រមូលពន្ធ ចំណូលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

- ទូទាត់ចំណាយដែលបានចេញអាណត្តិដោយអភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

- គ្រប់គ្រង និងបើកផ្តល់ថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

- រៀបចំរបាយការណ៍គណនេយ្យហិរញ្ញវត្ថុតាមកាលកំណត់

- ថែរក្សាទុកដាក់ឯកសារ សក្ខីបត្រ និង បញ្ជីគណនេយ្យរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ។

### មាត្រា ១៦.-

ប្រធានមន្ទីរសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ ប្រធានរតនាគារ ប្រធានសាខាឬថ្នាក់ពន្ធដារដែលបោះទីតាំងនៅថ្នាក់ក្រោមជាតិជាអ្នកទទួលប្រតិភូកម្មពីរដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ ដើម្បីជួយដល់ក្រុមប្រឹក្សា និង អភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិក្នុងការអនុវត្តច្បាប់នេះ ។

# ជំពូកទី ៣

## ថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

### ផ្នែកទី ១

#### គោលការណ៍គ្រប់គ្រងថវិកា

### មាត្រា ១៧.-

រដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវមានធនធានហិរញ្ញវត្ថុ និង ថវិកាសមស្រប ដើម្បីអនុវត្តរាល់មុខងារភារកិច្ចសម្រាប់អភិវឌ្ឍសេដ្ឋកិច្ច និង សង្គមកិច្ចនៅក្នុងដែនសមត្ថកិច្ចរបស់ខ្លួន ។ គម្រោងថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ ប្រចាំឆ្នាំត្រូវមានគ្រោង និង អនុញ្ញាតនូវប្រភពធនធាន និង បន្ទុកទាំងអស់ដោយត្រូវធានាឲ្យបាននូវតុល្យភាពនៃថវិកា ។

ថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវស្ថិតនៅក្រោមបទប្បញ្ញត្តិទាំងឡាយនៃច្បាប់ស្តីពីប្រព័ន្ធហិរញ្ញវត្ថុសាធារណៈ ។

### មាត្រា ១៨.-

ថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវ បានរៀបចំ និង អនុម័តប្រចាំឆ្នាំនីមួយៗ ។ ការិយបរិច្ឆេទនៃថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិចាប់ផ្តើមនៅថ្ងៃទី ០១ ខែ មករា ហើយបញ្ចប់នៅថ្ងៃទី ៣១ ខែធ្នូ ។

ថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវរៀបចំ និង អនុម័តដោយមានតុល្យភាពពិតប្រាកដរវាងចំណូល និង ចំណាយទៅតាមទម្រង់ និង ចំណាត់ថ្នាក់ថវិកា ដែលកំណត់ដោយប្រកាសរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ។

### មាត្រា ១៩.-

ថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវរៀបចំ អនុម័ត និង អនុវត្តស្របតាមគោលការណ៍ ដូចខាងក្រោម :

- ត្រូវផ្សព្វផ្សាយព័ត៌មានឲ្យបានពេញលេញអំពីការរៀបចំ និងការអនុវត្តថវិកា

- រាល់ចំណូល និងចំណាយទាំងអស់ត្រូវតែជាផ្នែកនៃថវិកាតែមួយគត់

- ថវិកាត្រូវបញ្ចូលចំណូល និងចំណាយទាំងអស់របស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

- ចំណូលត្រូវប្រមូល និងបង្ហាញជាទឹកប្រាក់សរុបដោយគ្មានការកាត់កងចំណាយណាមួយឡើយ

- គ្មានចំណូលណាមួយត្រូវបានកំណត់សម្រាប់ការចំណាយជាក់លាក់ណាមួយឡើយ លើកលែងតែមានការអនុញ្ញាតដែលកំណត់ដោយបទប្បញ្ញត្តិដោយឡែក

- សរុបគម្រោងចំណាយត្រូវធានាទាំងស្រុងដោយសរុបគម្រោងចំណូល

- គ្មានចំណូល ឬ ចំណាយណាមួយត្រូវប្រមូល ឬ ប្រើប្រាស់ក្រៅពីក្នុងថវិកាដែលបានអនុម័តឡើយ។

### មាត្រា ២០.-

រដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗត្រូវរៀបចំ អនុម័ត និង អនុវត្តក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យម ។

ក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យម ត្រូវបញ្ជាក់អំពីការព្យាករណ៍ដែលមានលក្ខណៈប្រាកដប្រជាលើមូលដ្ឋានចំណូលសម្រាប់រយៈពេលមធ្យម និង វិធានដែលចំណូលទាំងនេះត្រូវបានបែងចែកទៅតាមខ្ទង់ចំណាយនានារបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ។

ទម្រង់បែបបទសម្រាប់ការរៀបចំ និង ការអនុវត្តក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យមត្រូវកំណត់ដោយប្រកាសរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ។

រដ្ឋបាលថ្នាក់ក្រោមជាតិគ្មានសិទ្ធិក្នុងការខ្ចីប្រាក់ពីគេ ឲ្យប្រាក់គេខ្ចី បោះផ្សាយសញ្ញាប័ណ្ណ ឬ ផ្តល់ការធានា លិខិតធានា និង ធ្វើទង្វើណាដោយផ្ទាល់ ឬ ដោយប្រយោលដែលអាចនាំឲ្យកើតមាន

នូវបំណុល ឬ បន្ទុកហិរញ្ញវត្ថុផ្សេងទៀតដោយផ្ទាល់ ឬ ដោយប្រយោលដល់ព្រះរាជាណាចក្រកម្ពុជា បានទេ ។

ចំពោះការទទួលហិរញ្ញប្បទានឥតសំណង រដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវមានការឯកភាពជាមុន ពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ និង រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ។

### មាត្រា ២២.-

រដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវគ្រប់គ្រង និង ប្រើប្រាស់ថវិកាប្រកបដោយប្រសិទ្ធភាព តម្លាភាព និង គណនេយ្យភាពចំពោះប្រជាពលរដ្ឋរបស់ខ្លួន និង ចំពោះរាជរដ្ឋាភិបាល ដែលមានក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុជាសេនាធិការ ។

## ផ្នែកទី ២

### បន្ទុក និង ធនធានហិរញ្ញវត្ថុរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

### មាត្រា ២៣.-

ចំណាយថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ រួមមាន :

- ចំណាយប្រតិបត្តិការរដ្ឋបាល

- ចំណាយក្នុងការអនុវត្តមុខងារជាកាតព្វកិច្ច

- ចំណាយក្នុងការអនុវត្តមុខងារជាជម្រើស និង

- ចំណាយក្នុងការអនុវត្តតួនាទី ភារកិច្ចផ្សេងៗទៀត ដែលកំណត់ដោយច្បាប់ ឬ លិខិតបទដ្ឋានគតិយុត្តជាធរមានដទៃទៀត ។

### មាត្រា ២៤.-

ចំណូលថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ រួមមាន :

- ចំណូលពីប្រភពនៅមូលដ្ឋាន

- ចំណូលពីថ្នាក់ជាតិ

- ចំណូលផ្សេងៗទៀត ដែលកំណត់ដោយច្បាប់ ឬ លិខិតបទដ្ឋានគតិយុត្តដទៃទៀត ។

### មាត្រា ២៥.-

ចំណូលពីប្រភពនៅមូលដ្ឋានរួមមាន ចំណូលសារពើពន្ធ និងចំណូលមិនមែនសារពើពន្ធ :

១- ចំណូលសារពើពន្ធនៅមូលដ្ឋានជាចំណូលពន្ធ និង អាករដែលត្រូវបង្កើត និង កំណត់ដោយច្បាប់ក្នុងក្របខ័ណ្ឌច្បាប់ស្តីពីសារពើពន្ធ ដើម្បីជាគុណប្រយោជន៍ទាំងស្រុងដល់ថវិកា

របស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ។ ការបែងចែកប្រភេទ និង សមាមាត្រចំណូលពន្ធ និង អាករនៅមូលដ្ឋានរវាងរដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗត្រូវកំណត់ដោយអនុក្រឹត្យ ។

២- ចំណូលមិនមែនសារពើពន្ធនៅមូលដ្ឋានរួមមាន :

- ចំណូលដែលបានមកពីការជួលទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ កម្រៃសេវា និងចំណូលផ្សេងៗ

- ការបែងចែកចំណូលមិនមែនសារពើពន្ធ នៅមូលដ្ឋានរវាងរដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗ និង តារាងតម្លៃអតិបរមាសម្រាប់ការប្រមូលចំណូលពីកម្រៃសេវា និង ចំណូលផ្សេងៗ ត្រូវកំណត់ដោយអនុក្រឹត្យតាមសំណើរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ បន្ទាប់ពីមានការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ

- អំណោយដែលបានមកពីប្រភពខាងក្នុង និង ខាងក្រៅដែនសមត្ថកិច្ចរបស់ក្រុមប្រឹក្សានីមួយៗ

- ចំណូលពីប្រភពផ្សេងៗដែលកំណត់ដោយច្បាប់ ឬ លិខិតបទដ្ឋានគតិយុត្តដទៃទៀត ។

#### មាត្រា ២៦._

ប្រភពចំណូលពីថ្នាក់ជាតិ រួមមាន :

- ចំណូលចែករំលែក

- មូលនិធិផ្ទេរពីថវិកាថ្នាក់ជាតិ និង

- ថ្លៃសេវាបានមកពីមុខងារជាភ្នាក់ងារដែលអនុវត្តដោយក្រុមប្រឹក្សាក្នុងនាមក្រសួងស្ថាប័នរបស់រាជរដ្ឋាភិបាល ។

#### មាត្រា ២៧._

ចំណូលចែករំលែកគឺជាចំណូលដែលត្រូវចែករំលែករវាងថ្នាក់ជាតិ ជាមួយរដ្ឋបាលថ្នាក់ក្រោមជាតិពាក់ព័ន្ធ។ ប្រភពចំណូល និង សមាមាត្របែងចែកត្រូវកំណត់ដោយច្បាប់ ឬ អនុក្រឹត្យតាមសំណើរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ បន្ទាប់ពីមានការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។

#### មាត្រា ២៨._

មូលនិធិផ្ទេរពីថវិកាថ្នាក់ជាតិ រួមមានមូលនិធិផ្ទេរមានភ្ជាប់លក្ខខណ្ឌ និង មូលនិធិផ្ទេរគ្មានភ្ជាប់លក្ខខណ្ឌ ។

រដ្ឋបាលថ្នាក់ក្រោមជាតិមានសិទ្ធិទទួលពីថវិកាជាតិប្រចាំឆ្នាំ នូវមូលនិធិផ្ទេរមានភ្ជាប់លក្ខខណ្ឌ និង មូលនិធិផ្ទេរគ្មានភ្ជាប់លក្ខខណ្ឌ ដែលត្រូវធ្វើឡើងជាដំណាក់កាលៗសម្រាប់ឆ្នាំនីមួយៗ ។

នីតិវិធី និង បែបបទនៃការផ្ទេរមូលនិធិពីថវិកាជាតិទៅរដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវកំណត់ដោយអនុក្រឹត្យតាមសំណើរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ បន្ទាប់ពីមានការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។

#### មាត្រា ២៩._

មូលនិធិផ្ទេរមានភ្ជាប់លក្ខខណ្ឌ ជាមូលនិធិដែលរដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវប្រើប្រាស់ :

- ដើម្បីគ្រប់គ្រង ចាត់ចែង និង អនុវត្តមុខងារជាកាតព្វកិច្ចមួយ ឬ ច្រើនដែលត្រូវបានផ្ទេរឱ្យរដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗតាមការប្រគល់មុខងារ ឬ ការផ្ទេរប្រតិភូកម្មមុខងារ ឬ

- ដើម្បីបន្តគ្រប់គ្រង ឬ ចាត់ចែង និងអនុវត្តមុខងារជាជម្រើសមួយ ឬ ច្រើនដែលក្រសួងស្ថាប័នរបស់រាជរដ្ឋាភិបាលធ្លាប់បានអនុវត្ត ឬ

- សំរាប់គោលបំណងជាកាតព្វកិច្ចមួយឬច្រើនដែលបានកំណត់ ។

ទម្រង់បែបបទ វិធាន និង លក្ខខណ្ឌនៃការផ្ទេរមូលនិធិមានភ្ជាប់លក្ខខណ្ឌត្រូវកំណត់ដោយអនុក្រឹត្យតាមសំណើរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ បន្ទាប់ពីមានការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។

#### មាត្រា ៣០._

មូលនិធិផ្ទេរគ្មានភ្ជាប់លក្ខខណ្ឌ ជាមូលនិធិដែលរដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវប្រើប្រាស់ដើម្បី :

- បំពេញភារកិច្ចតាមផ្លូវច្បាប់

- បំពេញមុខងារភារកិច្ចក្នុងការបង្កើត ការជំរុញ និង ការធ្វើឲ្យមានជីវភាពដល់ការអភិវឌ្ឍតាមបែបប្រជាធិបតេយ្យ

- ចំណាយផ្នែករដ្ឋបាលរបស់ខ្លួន និង

- ជ្រើសរើស គ្រប់គ្រង ចាត់ចែង និង អនុវត្តមុខងារជាជម្រើសនានា ។

រដ្ឋបាលថ្នាក់ក្រោមជាតិមានសិទ្ធិទទួលពីថវិកាជាតិប្រចាំឆ្នាំ នូវមូលនិធិផ្ទេរគ្មានភ្ជាប់លក្ខខណ្ឌ ដោយផ្អែកតាមលក្ខណៈវិនិច្ឆ័យ និងរូបមន្តប្រកបដោយតម្លាភាព ។

ទម្រង់បែបបទ វិធាន និង លក្ខខណ្ឌនៃការផ្ទេរមូលនិធិគ្មានភ្ជាប់លក្ខខណ្ឌត្រូវកំណត់ដោយអនុក្រឹត្យតាមសំណើរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ បន្ទាប់ពីមានការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។

#### មាត្រា ៣១._

ត្រូវបង្កើតឲ្យមានមូលនិធិក្រុង ស្រុក ដែលមានគណនីដោយឡែកនៅធនាគារជាតិ ដើម្បីទទួលមូលនិធិផ្ទេរគ្មានភ្ជាប់លក្ខខណ្ឌពីថវិកាជាតិ និង ទទួលធនធានពីប្រភពផ្សេងៗទៀតសម្រាប់ជា

ប្រយោជន៍ដល់ថវិកាថ្នាក់រដ្ឋបាលក្រុង និង ស្រុក ។

មូលនិធិផ្ទេរគ្មានភ្ជាប់លក្ខខណ្ឌដែលត្រូវផ្ទេរពីថវិកាជាតិទៅមូលនិធិក្រុង ស្រុក ត្រូវធ្វើឡើងជាដំណាក់កាលៗក្នុងឆ្នាំនីមួយៗ តាមរូបមន្ត ឬ អត្រាជាក់លាក់ និង អាចប៉ាន់ប្រមាណបានសម្រាប់រយៈពេលមធ្យម។

ការវិភាជន៍ធនធានពីមូលនិធិក្រុង ស្រុកជូនទៅ រដ្ឋបាលថ្នាក់ក្រុង ស្រុកនីមួយៗ ត្រូវធ្វើឡើងប្រចាំឆ្នាំដោយផ្អែកតាមលក្ខណៈវិនិច្ឆ័យ និង រូបមន្តប្រកបដោយតម្លាភាព ។

ការបង្កើត និង វិធានអនុវត្តរបស់មូលនិធិក្រុង ស្រុក ត្រូវកំណត់ដោយអនុក្រឹត្យតាមសំណើរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុ បន្ទាប់ពីមានការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។

#### មាត្រា ៣២._

រដ្ឋបាលថ្នាក់ក្រោមជាតិអាចទទួលបាននូវចំណូលពីការអនុវត្តមុខងារជាភ្នាក់ងារ ក្នុងនាមក្រសួងស្ថាប័នរបស់រាជរដ្ឋាភិបាល ។

#### មាត្រា ៣៣._

រដ្ឋបាលថ្នាក់ក្រោមជាតិអាចទទួលបាននូវមុខងារជាភ្នាក់ងារក្នុងនាមរាជរដ្ឋាភិបាល ឬ ក្រសួងស្ថាប័នរបស់រាជរដ្ឋាភិបាល ដោយផ្អែកទៅតាមច្បាប់ ឬ លិខិតបទដ្ឋានគតិយុត្តដទៃទៀត ។

រដ្ឋបាលថ្នាក់ក្រោមជាតិអាចពិភាក្សាឯកភាពគ្នាជាមួយក្រសួងស្ថាប័ន ឬ មន្ទីរ អង្គភាពនានារបស់រដ្ឋបាលថ្នាក់ជាតិ ដើម្បីទទួលបានអនុវត្តនូវកិច្ចការអ្វីមួយតាមរយៈកិច្ចសន្យា ឬ កិច្ចព្រមព្រៀងដែលក្នុងនោះបានកំណត់ច្បាស់អំពីកិច្ចការដែលត្រូវធ្វើ ពេលវេលាដែលត្រូវអនុវត្ត លទ្ធផលដែលត្រូវសម្រេច និង ប្រាក់កម្រៃដែលភ្នាក់ងារអនុវត្តត្រូវទទួលបាន ។

ទម្រង់បែបបទ និង វិធាននៃការប្រើប្រាស់ថវិកាសម្រាប់អនុវត្តមុខងារជាភ្នាក់ងារខាងលើនេះ ត្រូវកំណត់ដោយប្រកាសរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ បន្ទាប់ពីមានការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។

### ផ្នែកទី ៣

### ការរៀបចំ និង ការអនុម័តថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

#### មាត្រា ៣៤.-

ផែនការយុទ្ធសាស្ត្រថវិកា និង គម្រោងថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវរៀបចំដោយអភិបាលនៃគណៈអភិបាល និង អនុម័តដោយក្រុមប្រឹក្សា ទៅតាមនីតិវិធីដែលកំណត់ដោយប្រកាសរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ។

គម្រោងថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិទាំងអស់ គឺជាកញ្ចប់ថវិកាមួយដែលត្រូវបញ្ជូនមកពិនិត្យអនុម័តដោយរដ្ឋសភា និង ព្រឹទ្ធសភា ក្នុងក្របខ័ណ្ឌនៃការពិនិត្យ និង អនុម័តច្បាប់ហិរញ្ញវត្ថុប្រចាំឆ្នាំនីមួយៗ ។ ក្រោយពីច្បាប់ហិរញ្ញវត្ថុប្រចាំឆ្នាំត្រូវបានពិនិត្យ និង អនុម័តពីរដ្ឋសភា និងព្រឹទ្ធសភារួចហើយ កញ្ចប់ថវិកានៃរដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវបែងចែកទៅតាមក្រុមប្រឹក្សានីមួយៗដោយប្រកាសរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ។

#### មាត្រា ៣៥._

គម្រោងថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវរៀបចំទៅតាមប្រតិទិនដូចខាងក្រោម :

១- ការរៀបចំផែនការយុទ្ធសាស្ត្រថវិកា (ពីខែមីនា ដល់ខែឧសភា)

រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុត្រូវចេញសេចក្តីណែនាំស្តីពីការរៀបចំយុទ្ធសាស្ត្រថវិកាដល់គ្រប់ក្រសួងស្ថាប័ន អង្គភាពទាំងអស់ដើម្បីជូនដំណឹងដល់ក្រុមប្រឹក្សានីមួយៗនូវកម្មវិធី និងគម្រោងថវិកាក្នុងវិស័យរបស់ខ្លួន ដែលត្រូវអនុវត្តនៅដែនសមត្ថកិច្ចរបស់ក្រុមប្រឹក្សានីមួយៗ ។ ក្នុងនាមក្រុមប្រឹក្សា អភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវរៀបចំផែនការយុទ្ធសាស្ត្រថវិការបស់ខ្លួន ដោយឈរលើមូលដ្ឋានផែនការអភិវឌ្ឍ កម្មវិធីវិនិយោគ និង ក្របខ័ណ្ឌចំណាយរយៈពេលមធ្យមរបស់រដ្ឋបាលនីមួយៗ នៃរដ្ឋបាលថ្នាក់ក្រោមជាតិ រួចហើយដាក់ជូនក្រុមប្រឹក្សារបស់ខ្លួនដើម្បីពិនិត្យ ពិភាក្សា និងអនុម័តហើយត្រូវផ្ញើជូនទៅមន្ទីរសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ដើម្បីបូកសរុបផ្ញើមកក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ យ៉ាងយឺតបំផុតត្រឹមថ្ងៃទី ១៥ ខែ ឧសភា ។

២- ការរៀបចំកញ្ចប់ថវិកា (ពីខែមិថុនា ដល់ខែកញ្ញា)

នៅសប្តាហ៍ទី ១ នៃ ខែ មិថុនា រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុត្រូវរៀបចំសារាចរណែនាំស្តីពីបច្ចេកទេសនៃការរៀបចំគម្រោងថវិកា ដោយបញ្ជាក់ពីទម្រង់បែបបទនីតិវិធីនៃការរៀបចំគម្រោងថវិកា និង ឯកសារពាក់ព័ន្ធដែលត្រូវភ្ជាប់ជាមួយ ហើយផ្ញើទៅរដ្ឋបាលថ្នាក់ក្រោមជាតិដើម្បីរៀបចំគម្រោងចំណូល ចំណាយថវិកាប្រចាំឆ្នាំរបស់ខ្លួន ។ អភិបាលនៃគណៈអភិបាលនីមួយៗនៅរដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវរៀបចំគម្រោងចំណូល ចំណាយថវិកាប្រចាំឆ្នាំរបស់ខ្លួន ដោយផ្អែកលើមូលដ្ឋានសារាចរណែនាំស្តីពីបច្ចេកទេសនៃការរៀបចំគម្រោងថវិកា និង អាទិភាពគោលនយោបាយនៃរដ្ឋបាលរបស់ខ្លួន ដោយដាក់បញ្ចូលនូវរាល់ប្រភពថវិកាទាំងអស់ដែលត្រូវអនុវត្តនៅក្នុងដែនសមត្ថកិច្ចរបស់ខ្លួន ។

គម្រោងថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវរៀបចំឡើងដោយអភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗ ដោយមានជំនួយពីប្រធានហិរញ្ញវត្ថុរបស់ក្រុមប្រឹក្សា និង មន្ត្រីនៃមន្ទីរសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ។ អភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗក្រោមកិច្ចប្រជុំក្រុមប្រឹក្សារបស់ខ្លួន ត្រូវធ្វើការផ្សព្វផ្សាយជាសាធារណៈនូវគម្រោងថវិកានេះដើម្បីប្រមូលយោបល់ចូលរួមរបស់ប្រជាពលរដ្ឋ និង អ្នកពាក់ព័ន្ធនានាក្នុងដែនសមត្ថកិច្ចរបស់ខ្លួន រួចហើយត្រូវ

ពិនិត្យ និង រៀបចំឡើងវិញនូវគម្រោងថវិកានេះ ដើម្បីដាក់ជូនក្រុមប្រឹក្សារបស់ខ្លួនពិភាក្សា និងអនុម័ត នៅក្នុងកិច្ចប្រជុំជាសាធារណៈយ៉ាងយឺតបំផុតត្រឹមថ្ងៃទី ៣០ ខែ មិថុនា ។

ចំពោះការរៀបចំគម្រោងថវិការដ្ឋបាលក្រុង ស្រុក រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុអាចធ្វើប្រតិភូកម្មឲ្យអភិបាលនៃគណៈអភិបាលខេត្តទទួលខុសត្រូវ ក្នុងការជួយគាំទ្របច្ចេកទេសដោយមានគម្រោងថវិការបស់ខ្លួនបានត្រឹមត្រូវ ស្របតាមបទប្បញ្ញត្តិនានានៃច្បាប់នេះ បទបញ្ជា បែបបទ និង នីតិវិធីនានា ដែលកំណត់ដោយថ្នាក់ជាតិ ។ អភិបាលនៃគណៈអភិបាលខេត្ត ត្រូវធ្វើសេចក្តីរាយការណ៍ក្នុងកិច្ចប្រជុំក្រុមប្រឹក្សារបស់ខ្លួនអំពីដំណើរការគាំទ្របច្ចេកទេសនេះ ។

អភិបាលនៃគណៈអភិបាលខេត្ត ត្រូវធានាថាមន្ត្រីនៃមន្ទីរសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ធ្វើការបូកសរុបគម្រោងថវិការបស់ខេត្ត គម្រោងថវិការបស់ក្រុង គម្រោងថវិការបស់ស្រុកក្នុងខេត្តរបស់ខ្លួនចូលក្នុងទម្រង់ដែលកំណត់ដោយក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ដោយភ្ជាប់ជាមួយនូវគម្រោងថវិកា និង សេចក្តីអត្ថាធិប្បាយពន្យល់របស់ខេត្ត របស់ក្រុង របស់ស្រុក ហើយត្រូវផ្ញើគម្រោង និងឯកសារទាំងនេះមកក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ យ៉ាងយឺតបំផុតត្រឹមថ្ងៃទី ១៥ ខែ កក្កដា ។

ក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុត្រូវធ្វើការប្រមូលផ្តុំបូកសរុបរាល់គម្រោងថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិសម្រាប់ឆ្នាំនីមួយៗ ។

ក្នុងអំឡុងខែសីហាទាំងមូល ក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុត្រូវធ្វើការពិនិត្យនីត្យានុកូលភាព និង បញ្ជាក់អនុលោមភាពលើថវិការបស់រាជធានី ថវិការបស់ខេត្ត ថវិការបស់ក្រុង និងថវិការបស់ស្រុក ។

រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុអាចធ្វើប្រតិភូកម្មនូវការពិនិត្យនីត្យានុកូលភាពទៅដល់អង្គភាពជំនាញរបស់ខ្លួន ឬ អាជ្ញាធរណាមួយនៃរដ្ឋបាលថ្នាក់ក្រោមជាតិតាមការចាំបាច់ ។

ដំណើរការពិនិត្យនីត្យានុកូលភាព ត្រូវមានការចូលរួមពីអភិបាលនៃគណៈអភិបាលរាជធានី ខេត្ត ក្រុង និង ស្រុកដែលតំណាងឲ្យក្រុមប្រឹក្សាជាម្ចាស់ថវិកា តំណាងក្រសួងមហាផ្ទៃ និង សមាសភាពដទៃទៀតដែលកំណត់ដោយក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ។ ក្នុងដំណើរការពិនិត្យនីត្យានុកូលភាពនេះ ក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ឬ អាជ្ញាធរដែលបានទទួលអំណាចប្រតិភូកម្មពីរដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុត្រូវធ្វើការពិនិត្យផ្ទៀងផ្ទាត់លើគោលការណ៍នៃការពិនិត្យនីត្យានុកូលភាព ដូចខាងក្រោម :

- គម្រោងថវិកាបានរៀបចំឡើងទៅតាមទម្រង់ចំណាត់ថ្នាក់ថវិកាបែបបទ និង នីតិវិធីដែលបានកំណត់

- មានការចូលរួមពីប្រជាពលរដ្ឋ និង អ្នកពាក់ព័ន្ធនានាក្នុងដំណើរការរៀបចំថវិកា

- ការគ្រោងឥណទានទៅតាមគោលការណ៍ចំណាយចាំបាច់

- គម្រោងថវិកាត្រូវគ្រោងតាមលក្ខខណ្ឌដែលភ្ជាប់ទៅនឹងការប្រើប្រាស់ធនធានពីប្រភពថ្នាក់ជាតិដែលបានកំណត់ទុកជាមុន

- ធានាឲ្យមានតុល្យភាពពិតប្រាកដរវាងចំណូល និង ចំណាយថវិកា

- មានការពិភាក្សាអនុម័តគម្រោងថវិកាក្នុងកិច្ចប្រជុំជាសាធារណៈរបស់ក្រុមប្រឹក្សា ។

ក្នុងករណីដែលក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ឬ អាជ្ញាធរដែលបានទទួលអំណាចប្រតិភូកម្មពីដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុពិនិត្យឃើញថាគម្រោងថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិណាមួយមិនស្របទៅនឹងគោលការណ៍ពិនិត្យនីត្យានុកូលភាពដូចបានចែងខាងលើ ក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ឬ អាជ្ញាធរដែលបានទទួលប្រតិភូកម្មអំណាចពីរដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ត្រូវសម្រេចកែសម្រួល និង ជូនដំណឹងជាលាយលក្ខណ៍អក្សរទៅអភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ដើម្បីរៀបចំកែសម្រួលឡើងវិញទៅតាមនីតិវិធីជាធរមាន ។

៣- ការអនុម័តថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ (ពីខែតុលា ដល់ខែធ្នូ)

នៅសប្តាហ៍ទី ១ នៃ ខែ តុលា ក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុបញ្ជូនគម្រោងថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ ដែលជាជំពូកមួយនៃសេចក្តីព្រាងច្បាប់ហិរញ្ញវត្ថុប្រចាំឆ្នាំដើម្បីដាក់ជូនគណៈរដ្ឋមន្ត្រីពិនិត្យ សម្រេច រួចដាក់ជូនរដ្ឋសភានៅសប្តាហ៍ទី ១ នៃ ខែ វិច្ឆិកា ដើម្បីពិនិត្យអនុម័តនិងដាក់ជូនព្រឹទ្ធសភានៅសប្តាហ៍ទី ១ នៃ ខែ ធ្នូ ដើម្បីសេចក្តីព្រាងច្បាប់នេះត្រូវបានអនុម័តជាស្ថាពរមុនថ្ងៃទី ២៥ នៃ ខែ ធ្នូ ។

#### មាត្រា ៣៦._

ប្រសិនបើគម្រោងថវិកាប្រចាំឆ្នាំរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ មិនត្រូវបានអនុម័តមុនថ្ងៃទី ០១ ខែ មករា នៃឆ្នាំសម្រាប់ការិយបរិច្ឆេទដែលត្រូវអនុវត្តនោះទេ៖ អភិបាលនៃរដ្ឋបាលថ្នាក់ក្រោមជាតិមានសិទ្ធិប្រមូលចំណូលតាមលក្ខខណ្ឌដែលបានអនុម័តដូចឆ្នាំមុន និង ធានាចំណាយប្រចាំខែ ក្នុងកម្រិត ១/១២ នៃថវិកាឆ្នាំមុន ។

### ផ្នែកទី ៤

### ការអនុវត្តថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

#### មាត្រា ៣៧._

ដើម្បីបម្រើឱ្យប្រតិបត្តិការចំណូល ចំណាយថវិកា រដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗត្រូវបើកគណនីប្រាក់បញ្ញើនៅធនាគារជាតិដែលពាក់ព័ន្ធ ។

#### មាត្រា ៣៨._

ថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិអាចត្រូវបានកែតម្រូវក្នុងអំឡុងឆ្នាំថវិកា ដើម្បីឆ្លើយតបទៅនឹងការប្រែប្រួលនៃលក្ខខណ្ឌសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុដែលជះឥទ្ធិពលទៅលើការព្យាករណ៍ដំបូងនៃ

ចំណូល និង ចំណាយ ។ ការកែតម្រូវថវិកាត្រូវរៀបចំពិនិត្យ អនុម័ត និង បញ្ជាក់ទទួលស្គាល់តាមនីតិវិធី ដូចមានចែងនៅក្នុង មាត្រា ៣៥ នៃច្បាប់នេះ ។

#### មាត្រា ៣៩._

ចលនាឥណទានផ្ទៃក្នុងនៃថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវធ្វើឡើងក្នុងលក្ខខណ្ឌដែលកំណត់ដោយប្រកាសរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ។ រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ អាចធ្វើប្រតិភូកម្មដល់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ក្នុងការធ្វើនិយ័តកម្មឥណទានរបស់ខ្លួន ដើម្បីដោះស្រាយតម្រូវការក្នុងករណីចាំបាច់បន្ទាន់ ។

#### មាត្រា ៤០._

ប្រភេទឥណទានថវិកានៃប្រភេទចំណាយមិនបានគ្រោងទុក អាចត្រូវបានប្រើប្រាស់សម្រាប់ធានាចំពោះចំណាយទាំងឡាយណាដែលការវិភាជន៍មិនបានកំណត់ជាក់លាក់ នៅពេលឥណទានត្រូវបានអនុម័ត ឬ សម្រាប់ឥណទានបំពេញបន្ថែមជាគុណប្រយោជន៍ដល់ប្រភេទចំណាយផ្សេងៗទៀតរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ។

អភិបាលត្រូវស្នើសុំការអនុម័តពីក្រុមប្រឹក្សារបស់ខ្លួន ពេលមានតម្រូវការប្រើប្រាស់ឥណទានចំណាយថវិកាមិនបានគ្រោងទុក ។

#### មាត្រា ៤១._

គម្រោង ឬ កម្មវិធីដែលអនុវត្តមិនទាន់ចប់នៅក្នុងឆ្នាំថវិកា ត្រូវបានដាក់បញ្ចូលដើម្បីបន្តអនុវត្តដោយលើកគម្រោងចំណាយទៅក្នុងថវិកានៃឆ្នាំបន្ទាប់ ។

#### មាត្រា ៤២._

ក្នុងករណីការអនុវត្តថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិធ្វើឲ្យលេចចេញនូវវិសមភាព រដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវម្ចាស់ការដាក់ចេញនូវវិធានការគ្រប់បែបយ៉ាង ដើម្បីធានាតុល្យភាពថវិកាឡើងវិញ ។ នៅចុងឆ្នាំថវិកា ប្រសិនបើចំណូលជាក់ស្តែងនៃថវិការបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ បានកើនលើសពីគម្រោងចំណូលប្រចាំឆ្នាំដែលបានគ្រោងទុក ឥណទានចំណាយថវិកាអាចត្រូវបង្កើនឡើង ឬ ធ្វើនិយ័តកម្មទៅជាគុណប្រយោជន៍ដល់ថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិដទៃនានា ដោយប្រកាសរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុទៅតាមកម្រិតចំណូលលើសដែលបានបញ្ជាក់ ។ នៅដំណាច់ឆ្នាំ ថវិកាអតិរេកថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវកត់ត្រាចូលគណនីលទ្ធផលនៃធនាគារជាតិ ។

#### មាត្រា ៤៣._

របាយការណ៍ហិរញ្ញវត្ថុប្រចាំឆ្នាំរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ ជាកម្មវត្ថុសម្រាប់ការធ្វើសវនកម្មផ្ទៃក្នុង និង សវនកម្មរបស់ស្ថាប័នមានសមត្ថកិច្ច ។ គោលបំណងនៃការធ្វើសវនកម្មផ្ទៃក្នុងហិរញ្ញវត្ថុ និង សវនកម្ម គឺសំដៅធានានូវតម្លាភាព គណនេយ្យភាព ប្រសិទ្ធភាព នៃប្រភពព័ត៌មានហិរញ្ញវត្ថុ និង ការវាយតម្លៃនៃការអនុវត្តថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ តាមប្រព័ន្ធគ្រប់គ្រងហិរញ្ញវត្ថុសាធារណៈ ។

របាយការណ៍អធិការកិច្ចហិរញ្ញវត្ថុ និង សវនកម្ម ដែលរួមមានបញ្ចូលនូវមតិយោបល់របស់ក្រុមប្រឹក្សានៃរដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវផ្សព្វផ្សាយជាសាធារណៈ ។

#### មាត្រា ៤៤._

កិច្ចប្រតិបត្តិការហិរញ្ញវត្ថុ និង គណនេយ្យ ត្រូវប្រតិបត្តិតាមវិធានទាំងឡាយស្តីពីការត្រួតពិនិត្យហិរញ្ញវត្ថុ ការគ្រប់គ្រងលទ្ធកម្មសាធារណៈ និង បទបញ្ជាទូទៅនៃគណនេយ្យសាធារណៈ ដែលត្រូវកំណត់ដោយច្បាប់ និង លិខិតបទដ្ឋានគតិយុត្តដទៃទៀត ។

#### មាត្រា ៤៥._

ការទូទាត់ថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ ជាជំពូកមួយនៃច្បាប់ទូទាត់ថវិកាទូទៅរបស់រដ្ឋ ។ គោរពតាមគោលការណ៍គណនេយ្យឯកភាព អភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ មានភារកិច្ចរៀបចំ និង ផ្តល់ជូនរដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុនូវរបាយការណ៍ស្តីពីការអនុវត្តថវិកា និង ព័ត៌មានចាំបាច់ផ្សេងៗទៀតនៅពេលដំណាច់ឆ្នាំថវិកានីមួយៗ ។

#### មាត្រា ៤៦._

នៅដំណាច់ឆ្នាំថវិកា អភិបាលនៃគណៈអភិបាលរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗ ត្រូវធ្វើការផ្ទៀងផ្ទាត់គណនេយ្យរដ្ឋបាលរបស់ខ្លួនជាមួយនិងគណនីគ្រប់គ្រងដោយគណនេយ្យករសាធារណៈរបស់រតនាគារ និង រៀបចំរបាយការណ៍ស្តីពីការអនុវត្តថវិកា ព្រមទាំងព័ត៌មានចាំបាច់ផ្សេងៗទៀតដើម្បីដាក់ជូនក្រុមប្រឹក្សាពិនិត្យ និង អនុម័ត និង ផ្ញើជូនមន្ទីរសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុធ្វើការបូកសរុបជារបាយការណ៍រួមរបស់រដ្ឋបាលរាជធានី ខេត្តនីមួយៗ រួចផ្ញើមកដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ដើម្បីបូកសរុបជាសេចក្តីព្រាងនៃការទូទាត់ថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិ និង ដាក់បញ្ចូលទៅក្នុងជំពូកមួយនៃសេចក្តីព្រាងច្បាប់ទូទាត់ថវិកាទូទៅរបស់រដ្ឋ ដែលត្រូវដាក់ទៅសុំការពិនិត្យ និង អនុម័តពីរដ្ឋសភា និង ព្រឹទ្ធសភា ។

### ជំពូកទី ៤

### ការគ្រប់គ្រងទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ

#### មាត្រា ៤៧._

ទ្រព្យសម្បត្តិរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិរួមមានទ្រព្យសម្បត្តិដែលផ្ទេរឲ្យ និង ទ្រព្យសម្បត្តិដែលរកបានដោយខ្លួនឯង ។ រដ្ឋផ្ទេរ និង ប្រគល់ឲ្យរដ្ឋបាលថ្នាក់ក្រោមជាតិនូវសិទ្ធិកាន់កាប់ និង ប្រើប្រាស់ទ្រព្យសម្បត្តិសាធារណៈរបស់រដ្ឋ និង ទ្រព្យសម្បត្តិឯកជនរបស់រដ្ឋមួយចំនួនដែលជាអចលនវត្ថុ ហើយស្ថិតនៅក្នុងដែនសមត្ថកិច្ចរបស់ក្រុមប្រឹក្សានីមួយៗទៅតាមការកំណត់របស់រដ្ឋ ។

ការផ្ទេរ ប្រគល់ទ្រព្យសម្បត្តិរបស់រដ្ឋទៅឲ្យរដ្ឋបាលថ្នាក់ក្រោមជាតិ ត្រូវធ្វើឡើងដោយអនុក្រឹត្យតាមសំណើរបស់រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ បន្ទាប់ពីការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ។ ការផ្ទេរ ប្រគល់ ត្រូវបានប្រតិបត្តិក្នុងលក្ខណៈដែលអាចដកហូតយកមកវិញបាន ។

#### មាត្រា ៤៨._

ការផ្ទេរទ្រព្យសម្បត្តិពីថ្នាក់ជាតិដើម្បីជាគុណប្រយោជន៍ដល់រដ្ឋបាលថ្នាក់ក្រោមជាតិ សម្រាប់ប្រើប្រាស់ជាសាធារណៈ ឬ សម្រាប់បំពេញនូវតម្រូវការនៃការសេវាសាធារណៈ ត្រូវសម្របទៅនឹងមុខងារ ដែលបានផ្ទេរទៅឲ្យរដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗ ។

#### មាត្រា ៤៩._

ទ្រព្យសម្បត្តិរបស់រដ្ឋ ដែលត្រូវបានផ្ទេរប្រគល់ឲ្យទៅរដ្ឋបាលថ្នាក់ក្រោមជាតិ ជាទ្រព្យសម្បត្តិដែលរដ្ឋបាលថ្នាក់ក្រោមជាតិអាចគ្រប់គ្រង ប្រើប្រាស់ និង ទាញយកផលចំណូលពីទ្រព្យសម្បត្តិទាំងនោះ ហើយរដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវថែរក្សាការពារឲ្យបានគង់វង្ស និង គ្មានសិទ្ធិលក់ដូរ ជួល ផ្ទេរកម្មសិទ្ធិ ឬ ផ្ទេរការប្រើប្រាស់ ដោយគ្មានការយល់ព្រមជាមុនពីរដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ បន្ទាប់ពីមានការឯកភាពពីរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃបានឡើយ ។

#### មាត្រា ៥០._

ទ្រព្យសម្បត្តិដែលរដ្ឋបាលថ្នាក់ក្រោមជាតិរកបានដោយខ្លួនឯង ជាកម្មសិទ្ធិផ្ទាល់ដែលរដ្ឋបាលថ្នាក់ក្រោមជាតិមានសិទ្ធិស្វ័យសម្រេចក្នុងការគ្រប់គ្រង និង ប្រើប្រាស់ដើម្បីទាញយកផលចំណូលពីទ្រព្យសម្បត្តិទាំងនោះ នៅក្នុងក្របខ័ណ្ឌដែលត្រូវកំណត់ដោយច្បាប់ ឬ លិខិតបទដ្ឋានគតិយុត្តដទៃទៀត ។

#### មាត្រា ៥១._

រដ្ឋបាលថ្នាក់ក្រោមជាតិត្រូវធ្វើបញ្ជីសារពើភណ្ឌទ្រព្យសម្បត្តិទាំងអស់របស់រដ្ឋបាលថ្នាក់ក្រោមជាតិ និង ត្រូវធ្វើបច្ចុប្បន្នភាពជារៀងរាល់ឆ្នាំ ហើយត្រូវបញ្ជូនទៅក្រសួងសេដ្ឋកិច្ច និង ហិរញ្ញវត្ថុ ដើម្បីបញ្ចូលក្នុងបញ្ជីសារពើភណ្ឌរួមនៃទ្រព្យសម្បត្តិរដ្ឋ ។

### ជំពូកទី ៥

### បទប្បញ្ញត្តិដោយឡែក

#### មាត្រា ៥២._

ក្នុងការអនុវត្តច្បាប់នេះដើម្បីឲ្យស្របទៅតាមតម្រូវការចាំបាច់ និង ផ្អែកតាមស្ថានភាព ជាក់ស្តែងរបស់រដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗរួមទាំងរដ្ឋបាលឃុំ សង្កាត់ផង រដ្ឋមន្ត្រីក្រសួងសេដ្ឋកិច្ច និងហិរញ្ញវត្ថុត្រូវពិភាក្សាជាមួយរដ្ឋមន្ត្រីក្រសួងមហាផ្ទៃ ដើម្បីស្នើឡើងនូវអនុក្រឹត្យ ឬ ចេញប្រកាសដោយឡែកសម្រាប់រដ្ឋបាលថ្នាក់ក្រោមជាតិនីមួយៗនោះ ។

### ជំពូកទី ៦

### ទោសប្បញ្ញត្តិ

#### មាត្រា ៥៣._

សមាជិកក្រុមប្រឹក្សា និង មន្ត្រីសាធារណៈគ្រប់ប្រភេទ និង គ្រប់ឋានៈដែលកំពុងបម្រើការងារ និង អ្នកដែលធ្លាប់បានបម្រើការងារកន្លងមក ហើយរកឃើញថាមិនបានគោរពតាមបទប្បញ្ញត្តិនៃច្បាប់នេះ ក្នុងការអនុវត្តមុខងារ និង ភារកិច្ចរបស់ខ្លួនដែលបានប្រគល់ជូន នឹងត្រូវទទួលទណ្ឌកម្មខាងវិន័យទៅតាមច្បាប់ និង លិខិតបទដ្ឋានគតិយុត្ត ដែលមានជាធរមាន ដោយមិនគិតដល់ទោសព្រហ្មទណ្ឌ និង ការទទួលខុសត្រូវផ្នែករដ្ឋប្បវេណីផ្សេងទៀត ព្រមទាំងត្រូវសងបង្គ្រប់ចូលថវិការដ្ឋបាលថ្នាក់ក្រោមជាតិវិញ នូវរាល់តម្លៃបាត់បង់ខូចខាតទ្រព្យសម្បត្តិ ឬ ប្រាក់កាសសាធារណៈរួមទាំងការប្រាក់លើតម្លៃបាត់បង់ខូចខាត ដែលបង្កឡើងដោយកំហុសឆ្គងនេះ ។

### អន្តរប្បញ្ញត្តិ

ច្បាប់ និង លិខិតបទដ្ឋានគតិយុត្តដែលពាក់ព័ន្ធនឹងរបបហិរញ្ញវត្ថុ និង ទ្រព្យសម្បត្តិរបស់ខេត្ត ក្រុង ដែលអនុវត្តកន្លងមកនៅមានសុពលភាពរហូតដល់មានច្បាប់ និង លិខិតបទដ្ឋានគតិយុត្តថ្មីមក

ជំនួសស្របតាមស្មារតីនៃច្បាប់ស្តីពីការគ្រប់គ្រងរដ្ឋបាលរាជធានី ខេត្ត ក្រុង ស្រុក ខណ្ឌ ច្បាប់ស្តីពីប្រព័ន្ធហិរញ្ញវត្ថុសាធារណៈ និង ច្បាប់នេះ ។
