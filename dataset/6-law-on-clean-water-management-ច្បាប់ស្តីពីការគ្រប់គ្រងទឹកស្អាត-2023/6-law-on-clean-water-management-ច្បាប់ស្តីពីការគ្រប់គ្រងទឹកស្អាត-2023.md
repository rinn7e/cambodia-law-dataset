# មាតិកា

## ច្បាប់ស្តីពីការគ្រប់គ្រងទឹកស្អាត
### មានចំនួន១៥ជំពូក និង ៦៥មាត្រា

### ជំពូកទី១ បទប្បញ្ញត្តិទូទៅ ( មាត្រា១ដល់មាត្រា៣ )

- មាត្រា១.-គោលបំណង

- មាត្រា២.-វិសាលភាព

- មាត្រា៣.-និយមន័យ

### ជំពូកទី២ សមត្ថកិច្ចគ្រប់គ្រង ( មាត្រា៤ដល់មាត្រា៥ )

- មាត្រា៤.-សមត្ថកិច្ចគ្រប់គ្រង

- មាត្រា៥.-គោលនយោបាយនិងផែនការ

### ជំពូកទី៣ គោលការណ៍( មាត្រា៦ )

- មាត្រា៦.-គោលការណ៍

### ជំពូកទី៤ មូលនិធិអភិវឌ្ឍន៍វិស័យទឹកស្អាត ( មាត្រា៧ )

- មាត្រា៧.-មូលនិធិអភិវឌ្ឍន៍វិស័យទឹកស្អាត

### ជំពូកទី៥ ការគ្រប់គ្រងអាជីវកម្មផ្គត់ផ្គង់ទឹកស្អាត ( មាត្រា៨ដល់មាត្រា២០ )

#### ផ្នែកទី១ ការផ្តល់អាជ្ញាបណ្ណធ្វើអាជីវកម្មផ្គត់ផ្គង់ទឹកស្អាត ( មាត្រា៨ដល់មាត្រា១៥ )

- មាត្រា៨.-លក្ខខណ្ឌទូទៅនៃអាជ្ញាបណ្ណ

- មាត្រា៩.-ប្រភេទនៃអាជ្ញាបណ្ណ

- មាត្រា១០.-ការសិក្សាសមិទ្ធិលទ្ធភាព

- មាត្រា១១.-ការឆ្លើយតបនិងការផ្តល់អាជ្ញាបណ្ណ

- មាត្រា១២.-នីតិវិធីនៃការផ្តល់អាជ្ញាបណ្ណ

- មាត្រា១៣.-សុពលភាពអាជ្ញាបណ្ណ

- មាត្រា១៤.-ការផ្ទេរ ការលក់ ការជួល និងការដាក់ប្រាតិភោគនូវអាជ្ញាបណ្ណ

- មាត្រា១៥.-ការបំពេញមុខងារដោយតតិយជន

#### ផ្នែកទី២ វិញ្ញាបនបត្រអនុញ្ញាតដំណើរការផ្គត់ផ្គង់ទឹកស្អាត ( មាត្រា១៦ដល់មាត្រា១៧ )

- មាត្រា១៦.-វិញ្ញាបនបត្រអនុញ្ញាតដំណើរការផ្គត់ផ្គង់ទឹកស្អាត

- មាត្រា១៧.-សុពលភាពវិញ្ញាបនបត្រអនុញ្ញាតដំណើរការផ្គត់ផ្គង់ទឹកស្អាត

#### ផ្នែកទី៣ កម្រៃសេវាសាធារណៈ ( មាត្រា១៨ )

- មាត្រា១៨.-ការបង់កម្រៃសេវាសាធារណៈ

#### ផ្នែកទី៤ ការពង្រីកតំបន់សេវាកម្ម( មាត្រា១៩ )

- មាត្រា១៩.-ការពង្រីកតំបន់សេវាកម្ម

#### ផ្នែកទី៥ លក្ខខណ្ឌស្តីពីការធ្វើអាជីវកម្មផ្គត់ផ្គង់ទឹកស្អាត( មាត្រា២០ )

- មាត្រា២០.-លក្ខខណ្ឌអាជីវកម្មផ្គត់ផ្គង់ទឹកស្អាត

### ជំពូកទី៦ ស្តង់ដារគុណភាពទឹក ( មាត្រា២១ដល់មាត្រា២២ )

- មាត្រា២១.-ស្តង់ដារគុណភាពទឹកស្អាត

- មាត្រា២២.-ការត្រួតពិនិត្យគុណភាពទឹក

### ជំពូកទី៧ ការប្រើប្រាស់ដី ប្រភពទឹក និងហេដ្ឋារចនាសម្ព័ន្ធរួម ( មាត្រា២៣ដល់មាត្រា២៥ )

- មាត្រា២៣.-ការប្រើប្រាស់ដី

- មាត្រា២៤.-ការប៉ះពាល់ដល់ហេដ្ឋារចនាសម្ព័ន្ធនៃប្រព័ន្ធផ្គត់ផ្គង់ទឹកស្អាត

- មាត្រា២៥.-ការគ្រប់គ្រង ការថែរក្សា និងការការពារប្រភពទឹក

### ជំពូកទី៨ ថ្លៃលក់ទឹកស្អាត ( មាត្រា២៦ដល់មាត្រា២៨ )

#### ផ្នែកទី១ ការកំណត់ថ្លៃលក់ទឹកស្អាត( មាត្រា២៦ )

- មាត្រា២៦.-ការកំណត់ថ្លៃលក់ទឹកស្អាត

#### ផ្នែកទី២ ការកែសម្រួលថ្លៃលក់ទឹកស្អាត( មាត្រា២៧ដល់មាត្រា២៨ )

- មាត្រា២៧.-ការពិនិត្យឡើងវិញនូវថ្លៃលក់ទឹកស្អាត

- មាត្រា២៨.-ការពិនិត្យលើសើរើថ្លៃលក់ទឹកស្អាតក្នុងករណីពិសេស

### ជំពូកទី៩ កាតព្វកិច្ចនិងសិទ្ធិរបស់ប្រតិបត្តិករ ( មាត្រា២៩ដល់មាត្រា៣៦ )

#### ផ្នែកទី១ កាតព្វកិច្ចរបស់ប្រតិបត្តិករ ( មាត្រា២៩ដល់មាត្រា៣៤ )

- មាត្រា២៩.-កាតព្វកិច្ចទូទៅ

- មាត្រា៣០.-ការគោរពតាមអនុលោមភាពតាមបទប្បញ្ញត្តិបច្ចេកទេស

- មាត្រា៣១.-ការផ្តល់ទិន្នន័យនិងព័ត៌មានអំពីការផ្គត់ផ្គង់ទឹកស្អាត

- មាត្រា៣២.-វិធានការបន្ទាន់

- មាត្រា៣៣.-ការធ្វើតេស្តគុណភាពទឹក

- មាត្រា៣៤.-វិធានការរក្សាអនាម័យប្រព័ន្ធផ្គត់ផ្គង់ទឹកស្អាត

#### ផ្នែកទី២ សិទ្ធិរបស់ប្រតិបត្តិករ ( មាត្រា៣៥ )

- មាត្រា៣៥.-សិទ្ធិមូលដ្ឋានរបស់ប្រតិបត្តិករ

#### ផ្នែកទី៣ សមាគមអ្នកផ្តល់សេវាផ្គត់ផ្គង់ទឹកស្អាត ( មាត្រា៣៦ )

- មាត្រា៣៦.-សមាគមអ្នកផ្តល់សេវាផ្គត់ផ្គង់ទឹកស្អាត

### ជំពូកទី១០ ការគ្រប់គ្រង ការត្រួតពិនិត្យប្រព័ន្ធផ្គត់ផ្គង់ទឹកស្អាត និងសមត្ថកិច្ចមន្ត្រីអធិការកិច្ច( មាត្រា៣៧ដល់មាត្រា៣៩ )

- មាត្រា៣៧.-ការគ្រប់គ្រងនិងការត្រួតពិនិត្យ

- មាត្រា៣៨.-ការតែងតាំងមន្ត្រីអធិការកិច្ច

- មាត្រា៣៩.-សិទ្ធិអំណាចរបស់មន្ត្រីអធិការកិច្ច

### ជំពូកទី១១ វិធានការក្នុងគ្រាអាសន្ន ( មាត្រា៤០ដល់មាត្រា៤១ )

- មាត្រា៤០.-ព្រឹត្តិការណ៍ដែលជាគ្រាអាសន្ន

- មាត្រា៤១.-វិធានការក្នុងគ្រាអាសន្ន

### ជំពូកទី១២ ការដោះស្រាយវិវាទ ( មាត្រា៤២ដល់មាត្រា៤៦ )

- មាត្រា៤២.-ការប្តឹងតវ៉ាចំពោះសេចក្តីសម្រេចបដិសេធរបស់ក្រសួងទទួលបន្ទុកវិស័យទឹកស្អាត

- មាត្រា៤៣.-ការប្តឹងតវ៉ាចំពោះសេចក្តីសម្រេចជាទណ្ឌកម្មរដ្ឋបាល

- មាត្រា៤៤.-ការប្តឹងតវ៉ាចំពោះវិធានការរបស់មន្ត្រីអធិការកិច្ច

- មាត្រា៤៥.-ការសម្រុះសម្រួលវិវាទរវាងប្រតិបត្តិករនិងប្រតិបត្តិករ

- មាត្រា៤៦.-វិវាទរវាងប្រតិបត្តិករនិងអ្នកប្រើប្រាស់ទឹកស្អាត

### ជំពូកទី១៣ ទោសប្បញ្ញត្តិ ( មាត្រា៤៧ដល់មាត្រា៦១ )

- មាត្រា៤៧.-ប្រភេទទណ្ឌកម្ម

- មាត្រា៤៨.-ការសិក្សាសមិទ្ធិលទ្ធភាពគម្រោងធ្វើអាជីវកម្មផ្គត់ផ្គង់ទឹកស្អាតដោយគ្មានការអនុញ្ញាត

- មាត្រា៤៩.-ការពិន័យអន្តរកាលចំពោះរូបវន្តបុគ្គល

- មាត្រា៥០.-ការពិន័យអន្តរកាលចំពោះនីតិបុគ្គល

- មាត្រា៥១.-ការមិនបានជូនដំណឹងអំពីផលប៉ះពាល់ដល់ហេដ្ឋារចនាសម្ព័ន្ធនៃប្រព័ន្ធផ្គត់ផ្គង់ទឹកស្អាត

- មាត្រា៥២.-ករណីដែលអំពើល្មើសត្រូវបានប្រព្រឹត្តម្តងទៀត

- មាត្រា៥៣.-ការធ្វើអាជីវកម្មផ្គត់ផ្គង់ទឹកស្អាតដោយគ្មានអាជ្ញាបណ្ណ

- មាត្រា៥៤.-ការមិនគោរពតាមស្តង់ដារគុណភាពទឹកស្អាត

- មាត្រា៥៥.-ការធ្វើឱ្យខូចខាតដោយចេតនានូវប្រព័ន្ធផ្គត់ផ្គង់ទឹកស្អាត

- មាត្រា៥៦.-ការយកទឹកដើម្បីប្រើប្រាស់ឬចែកផ្សាយបន្តដោយគ្មានការអនុញ្ញាត

- មាត្រា៥៧.-ការកែច្នៃឬផ្លាស់ប្តូរនាឡិកាទឹកដោយគ្មានការអនុញ្ញាត

#### មាត្រា៦៣ .- ការបន្តសុពលភាពអាជ្ញាបណ្ណដែលមានស្រាប់

#### មាត្រា៦៤ .- ការបន្តអានុភាពអនុវត្តនៃលិខិតបទដ្ឋានគតិយុត្តជាធរមាន

លិខិតបទដ្ឋានគតិយុត្តដែលពាក់ព័ន្ធនឹងការគ្រប់គ្រងទឹកស្អាតនិងការផ្តល់សេវាផ្គត់ផ្គង់ទឹកស្អាត ត្រូវមានអានុភាពអនុវត្តបន្តទៅមុខទៀត រហូតដល់មានលិខិតបទដ្ឋានគតិយុត្តថ្មីមកជំនួសស្របតាមបទប្បញ្ញត្តិនៃច្បាប់នេះ។

### ឧបសម្ព័ន្ធនៃច្បាប់ស្តីពីការគ្រប់គ្រងទឹកស្អាត

### សទ្ទានុក្រម

១- ការពង្រីកតំបន់សេវាកម្ម សំដៅដល់ការបង្កើនប្រព័ន្ធបណ្តាញផ្គត់ផ្គង់ទឹកស្អាតទៅខាងក្រៅតំបន់សេវាកម្មដែលខ្លួនកំពុងធ្វើការផ្គត់ផ្គង់ទឹកស្អាត។

២- ការសិក្សាសមិទ្ធិលទ្ធភាព សំដៅដល់ការសិក្សាពីកត្តាភូមិសាស្ត្រ ប្រជាសាស្ត្រ ប្រភពទឹក បច្ចេកទេសនិងហិរញ្ញវត្ថុ ដើម្បីបង្ហាញពីលទ្ធភាពនៃការផ្តល់សេវាផ្គត់ផ្គង់ទឹកស្អាតក្នុងតំបន់ណាមួយជាក់លាក់។

៣- តំបន់សេវាកម្ម សំដៅដល់តំបន់មួយដែលត្រូវបានកំណត់តាមបែបភូមិសាស្ត្រ ដែលនៅក្នុងតំបន់នោះប្រតិបត្តិករមានសិទ្ធិផ្តាច់មុខក្នុងការផ្តល់សេវាផ្គត់ផ្គង់ទឹកស្អាតជូនអតិថិជន ដោយអនុលោមតាមលក្ខខណ្ឌរបស់អាជ្ញាបណ្ណដែលត្រូវបានផ្តល់ដោយក្រសួងទទួលបន្ទុកវិស័យទឹកស្អាត។

៤- ថ្លៃលក់ទឹកស្អាត សំដៅដល់ចំនួនជាប្រាក់រៀល ដែលបានអនុញ្ញាតឱ្យប្រតិបត្តិករប្រមូលយកពីអតិថិជនរបស់ខ្លួន សម្រាប់ការផ្តល់សេវាផ្គត់ផ្គង់ទឹកស្អាតក្នុងឯកតាមួយម៉ែត្រត្រីគុណ ស្មើនឹង១០០០(មួយពាន់)លីត្រ។

៥- ថ្លៃសេវាផ្សេងៗ សំដៅដល់ថ្លៃដែលប្រតិបត្តិករប្រមូលពីអតិថិជន បន្ថែមពីលើថ្លៃលក់ទឹកស្អាត ដោយអនុលោមតាមកិច្ចព្រមព្រៀងជាវទឹក ដែលអាចរួមបញ្ចូលថ្លៃភ្ជាប់បណ្តាញ ថ្លៃផ្តាច់និងភ្ជាប់បណ្តាញឡើងវិញ ថ្លៃជួសជុល ថ្លៃពិន័យលើការទូទាត់យឺត ឬថ្លៃផ្សេងទៀតដែលត្រូវបានអនុញ្ញាតតាមច្បាប់នេះនិងលិខិតបទដ្ឋានគតិយុត្តជាធរមាន។

៦- ទឹកឆៅ សំដៅដល់ទឹកដែលបានមកពីប្រភពទឹកនានាដែលពុំទាន់បានឆ្លងកាត់ការធ្វើប្រព្រឹត្តិកម្ម។

៧- ទឹកស្អាត សំដៅដល់ទឹកដែលបានឆ្លងកាត់ការធ្វើប្រព្រឹត្តិកម្ម ហើយមានគុណភាព សុវត្ថិភាព និងអាចផ្គត់ផ្គង់បានដល់អតិថិជន។

៨- ប្រភពទឹក សំដៅដល់ទឹកលើដី ដែលរួមមានសមុទ្រ ទន្លេ ស្ទឹង ព្រែក ជ្រោះ ជ្រលងដងអូរ ប្រឡាយ បឹងបួ ត្រពាំង ស្រះ ថ្លុក អាងទឹក ទឹកក្រោមដីដែលហូរនៅក្រោមដីក្នុងចន្លោះថ្ម និងភាគល្អិតនៃដីដែលផ្លាស់ទី ពីកន្លែងមួយទៅកន្លែងមួយទៀត ទឹកភ្លៀង និងបង្គុំនៃទឹកក្នុងទម្រង់ទ្រាយផ្សេងៗទៀត។

៩- ប្រព្រឹត្តិកម្ម សំដៅដល់ដំណើរការកែប្រែគុណភាពទឹកពីទឹកឆៅឱ្យទៅជាទឹកស្អាត តាមរយៈបច្ចេកវិទ្យាសម្អាតទឹកផ្សេងៗ។

១០- ប្រព័ន្ធប្រព្រឹត្តិកម្ម សំដៅដល់ហេដ្ឋារចនាសម្ព័ន្ធសម្រាប់ដំណើរការកែប្រែគុណភាពទឹក ដោយរាប់ចាប់ពីស្ថានីយបូមទឹកឆៅ រហូតដល់អាងស្តុកទឹកស្អាត។

១១- ប្រព័ន្ធផ្គត់ផ្គង់ទឹកស្អាត សំដៅដល់ប្រព័ន្ធប្រព្រឹត្តិកម្ម ប្រព័ន្ធបណ្តាញផ្គត់ផ្គង់ទឹកស្អាត និងមធ្យោបាយដឹកជញ្ជូនសេវាផ្គត់ផ្គង់ទឹកស្អាតនានា។

១២- បុគ្គល សំដៅដល់រូបវន្តបុគ្គលឬនីតិបុគ្គល។

១៣- មធ្យោបាយតភ្ជាប់សេវាផ្គត់ផ្គង់ទឹកស្អាត សំដៅដល់បំពង់ទឹកស្អាតភ្ជាប់ទៅនឹងប្រព័ន្ធបណ្តាញផ្គត់ផ្គង់ទឹកស្អាត និងឧបករណ៍បរិក្ខារតភ្ជាប់សេវាផ្គត់ផ្គង់ទឹកផ្សេងៗទៀត រហូតទៅដល់នាឡិកាវាស់ស្ទង់ទឹកស្អាតតាមទីតាំងរបស់អតិថិជន។

១៤- ប្រព័ន្ធបណ្តាញផ្គត់ផ្គង់ទឹកស្អាត សំដៅដល់ស្ថានីយបូមចែកចាយ អនុស្ថានីយបូមចែកចាយ បំពង់មេ បំពង់រង និងអាងអាកាស។

១៥- វិញ្ញាបនបត្រអនុញ្ញាតដំណើរការផ្គត់ផ្គង់ទឹកស្អាត សំដៅដល់លិខិតចេញដោយក្រសួងទទួលបន្ទុកវិស័យទឹកស្អាត អនុញ្ញាតឱ្យប្រតិបត្តិករប្រើប្រាស់ប្រព័ន្ធផ្គត់ផ្គង់ទឹកស្អាតរបស់ខ្លួន ដើម្បីផ្តល់សេវាផ្គត់ផ្គង់ទឹកស្អាតនៅក្នុងតំបន់សេវាកម្មរបស់ខ្លួន។

១៧- ប្រតិបត្តិករ សំដៅដល់បុគ្គលដែលទទួលបានអាជ្ញាបណ្ណធ្វើអាជីវកម្មផ្គត់ផ្គង់ទឹកស្អាត។

១៨- សេវាផ្គត់ផ្គង់ទឹកស្អាត សំដៅដល់ការផ្គត់ផ្គង់ទឹកស្អាតដែលផ្តល់ដោយប្រតិបត្តិករជូនដល់អតិថិជននិងមានលក្ខណៈអាជីវកម្ម។

១៩- អាជ្ញាបណ្ណធ្វើអាជីវកម្មផ្គត់ផ្គង់ទឹកស្អាត សំដៅដល់លិខិតចេញដោយក្រសួងទទួលបន្ទុកវិស័យទឹកស្អាត ដែលផ្តល់ជូនប្រតិបត្តិករ ដោយមានកំណត់លក្ខខណ្ឌ សិទ្ធិ និងការទទួលខុសត្រូវក្នុងការវិនិយោគ ដំណើរការអាជីវកម្ម និងសេវាផ្គត់ផ្គង់ទឹកស្អាត នៅក្នុងតំបន់សេវាកម្មជាក់លាក់ណាមួយ ដែលបានកំណត់ព្រំប្រទល់ច្បាស់លាស់។
